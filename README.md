# Linear-Regression-using-an-Healthcare-Data-
[Health_data.ipynb](https://github.com/user-attachments/files/32568052/Health_data.ipynb)
[Health_data_transform.csv](https://github.com/user-attachments/files/32568081/Health_data_transform.csv)


In this project, I worked with a healthcare dataset with the aim of understanding the factors associated with systolic blood pressure and using machine learning to predict systolic blood pressure.  
The main stages of my analysis were data cleaning, handling missing values and outliers, transforming categorical variables, investigating multicollinearity, building regression models, applying regularization, making predictions, and evaluating the models.

I started by cleaning the data, standardizing categorical values, correcting data types, handling missing values, removing duplicates, and examining outliers.

I then transformed categorical variables into numerical features and investigated relationships between predictors using correlation analysis.

After separating my predictors from the target, I standardized the features, divided the data into training and testing sets, and trained both ordinary linear regression and Ridge regression models.

I evaluated the models using MSE, MAE and R-squared, and I also examined residuals and actual-versus-predicted plots to understand the model's errors and predictions.

Overall, this project helped me understand not only how to build a regression model, but also why data preparation, multicollinearity, regularization, model evaluation and residual analysis are important parts of the machine-learning process.
